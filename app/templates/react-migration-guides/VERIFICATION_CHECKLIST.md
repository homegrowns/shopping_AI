# React 마이그레이션 검증 체크리스트

## 실행 환경

- [ ] 의존성 설치가 정상 완료된다.
- [ ] 개발 서버가 오류 없이 실행된다.
- [ ] production build가 성공한다.
- [ ] 브라우저 콘솔에 초기 렌더 오류가 없다.

## 화면

- [ ] 제목이 `Shopping AI Assistant`로 표시된다.
- [ ] 채팅 로그, 미리보기, composer 순서가 유지된다.
- [ ] 사용자 메시지는 오른쪽, 어시스턴트 메시지는 왼쪽에 표시된다.
- [ ] 상품 결과가 반응형 그리드로 표시된다.
- [ ] 900px 이하 레이아웃과 모바일 화면에서 가로 스크롤이 생기지 않는다.

## 입력과 파일

- [ ] 텍스트만 입력해 전송할 수 있다.
- [ ] 이미지만 선택해 전송할 수 있다.
- [ ] 텍스트와 이미지를 함께 전송할 수 있다.
- [ ] 둘 다 없을 때는 요청하지 않는다.
- [ ] 이미지 선택 시 미리보기가 표시된다.
- [ ] 이미지 삭제 시 파일 입력과 미리보기가 함께 초기화된다.
- [ ] 같은 파일을 삭제 후 다시 선택할 수 있다.
- [ ] Enter는 전송한다.
- [ ] Shift+Enter는 줄바꿈한다.
- [ ] 한글 IME 조합 중 Enter가 잘못 전송되지 않는다.

## 메시지 상태

- [ ] 전송 즉시 사용자 메시지가 표시된다.
- [ ] 처리 중 어시스턴트 로딩 메시지가 표시된다.
- [ ] 새 메시지가 추가될 때 아래로 스크롤된다.
- [ ] 요청 중 전송 버튼이 비활성화된다.
- [ ] 성공 또는 실패 후 전송 버튼이 다시 활성화된다.

## 이미지 업로드 API

- [ ] `{API_BASE}/products` 요청의 method가 POST다.
- [ ] 요청 JSON에 `content_type`과 `session_id`가 전달된다.
- [ ] 응답의 새 `session_id`가 상태에 저장된다.
- [ ] `presigned_url` 요청의 method가 PUT이다.
- [ ] PUT 요청의 Content-Type이 선택 파일 타입과 같다.
- [ ] 반환된 `s3_key`가 검색 요청에 전달된다.
- [ ] presigned URL 요청 실패가 사용자에게 표시된다.
- [ ] S3 PUT 실패가 사용자에게 표시된다.

## 검색 API

- [ ] `/search?top_k=8` 요청의 method가 POST다.
- [ ] `session_id`, 선택적 `message`, 선택적 `s3_key`가 FormData로 전달된다.
- [ ] `answer`가 어시스턴트 상태 문구로 표시된다.
- [ ] 결과가 없고 답변도 없으면 빈 결과 문구가 표시된다.
- [ ] HTTP 오류 상태가 사용자에게 표시된다.
- [ ] 응답의 `error` 필드가 사용자에게 표시된다.
- [ ] `results`가 누락되어도 앱이 중단되지 않는다.

## 상품 카드

- [ ] 상품 이미지와 제목이 표시된다.
- [ ] 최고가와 최저가가 없을 때 `??`가 표시된다.
- [ ] 판매처가 표시된다.
- [ ] 유효한 상품 링크만 열 수 있다.
- [ ] 링크가 새 탭에서 안전하게 열린다.
- [ ] 이미지 로드 실패가 레이아웃을 깨뜨리지 않는다.
- [ ] 각 이미지에 적절한 대체 텍스트가 있다.

## React 품질

- [ ] `document.createElement`, `appendChild`, `querySelector`로 UI를 조작하지 않는다.
- [ ] `innerHTML` 또는 `dangerouslySetInnerHTML`을 사용하지 않는다.
- [ ] `window`에 이벤트 함수를 등록하지 않는다.
- [ ] 모든 동적 목록에 안정적인 React key가 있다.
- [ ] Blob URL을 교체·삭제·unmount 시 해제한다.
- [ ] API 로직과 프레젠테이션 컴포넌트가 분리되어 있다.
- [ ] 불필요한 외부 상태관리 라이브러리를 사용하지 않는다.

## 자동 검증

- [ ] lint가 통과한다.
- [ ] 관련 테스트가 통과한다.
- [ ] production build가 통과한다.
- [ ] 실행한 명령과 결과가 완료 보고에 기록되어 있다.
